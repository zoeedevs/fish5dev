## how to install

1. install [Fabric for 26.2](https://fabricmc.net/use/installer/).
2. install [Fabric API](https://modrinth.com/mod/fabric-api) & [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin).
3. download the latest jar from the [releases page](https://github.com/zoeedevs/fish5dev/releases).
4. put fish5 & the other jar files into `.minecraft/mods`.
5. launch Minecraft (make sure you're on the Fabric profile).

`/f5` opens the GUI.
